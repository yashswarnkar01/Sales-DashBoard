# Sales Dashboard – Return Analysis | Power BI

## Project Overview
This project is an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance and product returns. It provides insights into total sales, total orders, returns, return percentages, customer return behavior, shipping days, geographical distribution, and monthly profit and sales trends.

## Objectives
- Analyze overall sales and order performance.
- Measure total product returns and return percentage.
- Identify product categories with the highest returns.
- Analyze customer returns and shipping-day patterns.
- Understand geographical return distribution.
- Compare return percentages across markets and product categories.
- Track monthly profit and sales trends.

## Key Performance Indicators (KPIs)
The dashboard includes the following KPIs:

- **Total Sales:** 96,00,361.51
- **Total Orders:** 25,728
- **Total Returns:** 1,079
- **Return Percentage:** 4.19%

## Dashboard Visualizations

### 1. Total Returns by Category
A horizontal bar chart showing returns across Office Supplies, Technology, and Furniture. Office Supplies has the highest number of returns among the three categories.

### 2. Top 3 Customers Based on Returns
A column chart highlighting the top three customers based on return counts.

### 3. Total Returns by Shipping Days
A line chart showing how the number of returns varies with shipping days. It helps identify shipping durations associated with higher returns.

### 4. Total Returns by City
A geographical map displaying the distribution of returns across different locations worldwide.

### 5. Return Percentage by Market and Category
A stacked column chart comparing return percentages across different markets and product categories, including Furniture, Office Supplies, and Technology.

### 6. Profit and Sales by Month
A combined chart comparing monthly profit and sales to understand trends in business performance.

## Interactive Features
- Year slicer to filter dashboard results by year.
- Country filter for focused geographical analysis.
- Interactive charts for exploring sales and return patterns.
- A separate Details page for additional analysis.

## Tools and Technologies
- **Microsoft Power BI:** Dashboard development and visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Calculated measures and KPI analysis.
- **Data Modeling:** Relationships between orders, returns, products, customers, and date tables.

## Key Insights
- Office Supplies has the highest number of returns among the three displayed categories.
- The overall return percentage is 4.19%.
- Return patterns vary across shipping days and geographical locations.
- Return percentages differ across markets and product categories.
- Monthly sales and profit trends provide insights into business performance.

## Business Value
This dashboard helps businesses monitor sales and returns, identify categories with higher return volumes, understand customer and geographical return patterns, and evaluate monthly sales and profitability. These insights can support better operational planning and data-driven decision-making.

## Conclusion
This project demonstrates the use of Power BI to transform sales and return data into meaningful visual insights. It combines KPIs, interactive filters, geographical analysis, and trend visualizations to support business performance analysis.
